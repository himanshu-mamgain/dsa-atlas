# Practice

1. Read problem — don’t look at solution
2. Identify pattern (which category does this belong to?)
3. Write brute force first
4. Optimise with pattern
5. Code clean solution
6. Check time + space complexity
7. Test with edge cases
8. If stuck > 20 min — read hint only, not full solution
9. Write the pattern's invariant in one line before moving on

# Pattern Recognition

| Sorted array, find pair/target | Two Pointers |
| Subarray/substring with condition | Sliding Window |
| Sorted array, O(log n) | Binary Search |
| Frequency, count, pair lookup | Hash Map |
| Matching brackets, next greater | Stack |
| Shortest path, level order | BFS |
| All paths, cycle detection, islands | DFS |
| All subsets/permutations | Backtracking |
| Prefix search, word match | Trie |
| Min/max of dynamic set | Heap |
| Range sum queries | Prefix Sum |
| Connected components | Union Find |
| Overlapping subproblems, optimal | DP |
| Dependencies, ordering | Topological Sort |
